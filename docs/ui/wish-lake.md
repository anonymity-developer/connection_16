# MAKE A WISH 호수·목록 UI

2026-11-09. 기준: TAGME_integration_dm_verified_86ad1dd의 누적 소스(인증 DM 포함). 기존 6개 PR의 기능·백엔드·API·DB·외부 연동은 변경하지 않는다.

## 구현

- 미션 잠김 상태에서도 호수 그림을 볼 수 있다. 기존 해금·로그인 조건 없이 글을 쓰거나 공개 소원을 요청하지 않는다.
- 해금 후에는 자기 소원을 쓰지 않아도 기존 공개 API 결과를 호수로 탐색한다. `ContentMission`은 `feed.items`만 `WishGallery`에 전달하고 `own/latestRevision`을 섞지 않는다.
- 서버 `ContentRepository.feed`의 기존 공개 조건(승인본·VISIBLE·ACTIVE·공개 자격·현재 동의)을 재사용한다. 프론트가 승인 여부를 새로 결정하지 않는다. 공개 응답에는 검수 상태 필드가 없으므로 프론트 단독으로 공개 적격성을 검증할 수는 없다.
- 한 화면 최대 6개 동전, 고정 3×2 그리드와 불러온 결과 내 페이지 전환. 더 많은 서버 데이터는 기존 커서 `이전 글 더 보기`로 요청한다. 번호는 현재 불러온 목록의 탐색 번호이며 ID·점수·순위가 아니다.
- 소원을 선택하면 호수 아래 인라인 내용과 기존 `WishComments`를 연다. 제목으로 포커스를 이동하고 닫을 때 원래 동전으로 복귀한다. 별도 모달·댓글 API·추가 보상을 만들지 않는다.
- 목록 보기는 같은 공개 소원을 전체 카드로 읽는 대안이다. 항상 익명으로 표시하며 이름·프로필 링크·운 점수는 추가하지 않는다.
- 기존 성공 응답의 revision ID와 `createWishFeedback`을 재사용한다. 실패 시 receipt 없음, 같은 revision 중복 연출 방지, 새로고침 시 receipt 제거. 보기 전환은 호수 DOM을 유지해 동전을 다시 던지지 않는다.
- 접수 연출은 공개 동전이 아니다. 검수 대기/반려 소원은 호수에 올라가지 않으며 A는 기존 서버의 승인·완료 값에만 따른다. 수정 중 기존 승인본 공개 정책도 그대로다.
- 물결·동전은 기존 짧은 CSS 연출을 재사용하며 reduced-motion에서는 움직임을 없애고 접수 텍스트를 유지한다.

## 미리보기·목록 대안

개발 서버에서 `/wish-lake-preview.html`을 연다. 별도 Vite 개발 entry이며 가상 데이터만 사용하고 API를 호출하지 않는다. 기본 production build에는 해당 HTML·데이터가 포함되지 않는다. 운영 미션 페이지에 미리보기 전환이나 가상 데이터를 넣지 않는다.

실제 UI의 `목록으로 보기` 버튼을 사용하면 목록으로 즉시 비교할 수 있다. 검수 후 목록을 기본으로 택한다면 `ContentMission.tsx`의 `WishGallery`에 `initialView="list"`를 지정하는 한 곳만 변경하면 된다. 제출·댓글·페이지네이션은 두 보기에서 같은 계약을 쓴다.

## 검증 범위

프론트 lint/build, 기존 77개+신규 6개=83개 테스트 PASS. 신규 검사는 순수 페이지 분할·실제 React SSR·공개 소원 익명/이스케이프·접수 상태·소스 연결 계약을 검증한다. SSR은 실제 클릭·CSS 배치 검증이 아니다.

기존 `frontend/scripts/check-content-ui.mjs`의 가상 API 브라우저 시나리오에 승인 소원 8개·360/390/430/1440px 충돌/타깃 크기·키보드 선택/포커스 복귀·기존 댓글·목록 전환을 추가했다. Work에서 실행을 시도했지만 Chromium 실행 파일이 없어 NOT_VERIFIED다. 기존 브라우저 시나리오의 제출 실패/대기/반려/재검수/새로고침/멱등 재시도 검사 역시 실행되지 않았다. 실제 Spring/DB·실기기·NFC는 미검증이다.

디자인은 기존 파스텔/겨울 톤을 보존한다. 호수 수면의 그림용 색상 변화와 작은 동전 그림자는 요청한 호수·스티커 표현에만 사용한다. 새 화면 구조·서체·장식 라이브러리는 추가하지 않는다. 조작 동전은 56px, 목록 전환은 텍스트+눌림 상태, 소원 본문은 별도 읽기 영역으로 둔다.
