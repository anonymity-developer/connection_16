# 2026-11-12 확정 미션 안내와 기록

기존 [참여 계약](participation.md), [콘텐츠 계약](content.md), [결과 계약](results.md)을 보완한다. 사용자 승인 후 PR #21에 반영했으며 병합·운영 배포는 별도 승인 대상이다.

## 화면과 현장 안내

게임 소개와 이름은 상단에 한 번 표시한다. 중앙에는 참여 화면 또는 본인 프로필·결과·작성한 글을 보여준다. 이벤트 팁은 모든 상태에서 접힌 미션 안내의 TIP 항목에 표시한다. 지속적인 `글자 획득 완료` 표시는 **나의 진행 현황**의 글자 이미지 옆에 한 번만 둔다. 미션 안내 토글·내용·TIP은 모바일/태블릿/PC 모두 진행 현황 아래 전체 너비로 배치한다. 새로운 서버 완료를 알리는 일시적 획득 대화상자는 유지하며 게임을 떠나지 않아도 된다.

| 미션 | 위치·조건 |
| --- | --- |
| SHOW ME / 소개 S | 1층 안내와 미션 공지. NFC 없이 프로필 저장으로 획득. 한 줄 소개·관심사 1개 이상·현재 참여/공개 동의 필요 |
| SYNC ME / 취향 S | 1층 S NFC. 최초 제출 결과 확정, 재참여 불가. 결과에서 비슷한 성향의 동료 탐색 |
| A WISH COME TRUE / A | 10층 A NFC. 계정당 소원 하나, 400자 이내, 수정 가능. 다른 소원에 댓글 가능 |
| FAST TAP / F | 19층과 20층 사이 계단 F NFC. 공식 도전 1회, 준비 5초·입력 10초. 공식 도전 완료 후 상위 10명 공개, 10위 진입 시 50자 한마디 |
| YOU GOT THIS / Y | 19층 Y NFC. 계정당 응원 하나, 400자 이내, 수정 가능. 다른 응원에 하트 가능 |

소원과 응원의 공개 방식 안내는 다음으로 확정했다.

> 익명 또는 닉네임으로 공개할 수 있어요. 서로를 배려하는 표현을 사용해 주세요.

소원 카드 형태/색상은 PLAIN/ROSE를 유지한다. 두 종류 모두 revision별 anonymous를 저장하며 공개 선택 시 현재 공개 가능한 작성자의 닉네임/프로필 링크를 제공한다. 기존 익명 글은 소유자가 명시적으로 수정하기 전까지 익명이다. 댓글은 기존 200자 제한을 유지한다. 본문은 HTML로 해석하지 않는다.

홈의 전체 미션 힌트는 기존 세 문구를 3초마다 순서대로 반복한다. 다른 응원 버튼은 제거하며 읽는 중 마우스·키보드 포커스와 숨겨진 탭에서는 전환을 멈춘다. 문구 교체 애니메이션이나 반복 음성 알림은 사용하지 않는다.

## FAST TAP 공개 순위와 소감

- 서버에서 VALID로 확정한 현재 회차 공식 기록만 공개 순위에 포함한다. 현재 슬롯·완료 근거·ACTIVE 계정·공개 프로필·가져온 필수 정보·현재 두 동의를 함께 확인한다. 순서는 탭 수 내림차순, 제출 시각 오름차순, 시도 ID 오름차순이다.
- 공개 목록은 최대 10명이며 닉네임·프로필 이동용 profileId·횟수·순위·제출 시각·작성한 한마디를 반환한다. 타인의 시도 ID나 실명은 반환하지 않는다. 본인은 10위 밖에서도 자신의 기록과 순위를 확인한다.
- VALID 확정 트랜잭션에서 기존 **보관되지 않은 VALID 공식 기록**의 최고 탭 수를 엄격히 넘어야 기록 갱신 권한을 부여한다. 최초 기록도 포함하고 동점은 제외한다. 동시 확정과 관리자의 초기화는 하나의 `tap_record_lock`을 사용한다. 다른 참가자의 사용자 행은 잠그지 않는다.
- 2026-11-13 승인: 유효 기록 확정 또는 본인 순위 조회 시 상위 10위에 들면 한마디 권한을 부여하고 추월당해도 유지한다. 기존 최고 기록 갱신자의 권한도 유지한다. 새 한마디는 50자 이내로 해당 시도에 한 번만 저장하며 수정하지 않는다. 기존 51~100자 글은 잘라내지 않고 보존한다. 같은 키/내용 재시도만 같은 결과를 반환한다. 새로운 소감 작성은 OPEN에서만 허용한다. 마감 후에도 기존 요청의 동일 재시도와 순위 조회는 가능하다.
- 요청에는 세션·CSRF·Idempotency-Key·본인 시도·현재 해금·현재 프로필/동의와 `X-Participation-Generation` 검사가 필요하다. 응답 유실 시 화면은 입력을 잠그고 동일 키/본문으로 재전송한다. 409는 재조회, 401/403은 개인 상태 제거로 처리한다.
- 관리자 소프트리셋은 기존 시도와 연결된 소감을 보관하고 현재 순위에서 제외한다. 태그는 유지하며 새 회차에 다시 도전할 수 있다. 이전 회차 요청은 새 회차를 바꾸지 못한다.

## 추천과 익명 경계

사용자 승인에 따라 공개 여부와 무관하게 조회자와 후보 사이의 하트·소원 댓글을 내부 추천 순서에 반영한다. 유효한 상호작용 종류 수(하트 존재 + 댓글 존재, 0~2)를 먼저 비교하고, 기존 미방문·공통 관심사·같은 유형·다른 반·ID 순서를 이어서 사용한다. 양방향을 포함하며 반복 댓글 수를 점수로 누적하지 않는다. 숨김·보관·미승인 글과 삭제된 하트는 제외한다.

내부 점수·익명 작성자/수신자·상호작용 이유는 공개 DTO에 추가하지 않는다. 익명 콘텐츠/댓글의 nickname/profileId는 null로 유지한다. 공개 그래프의 간선과 점수는 기존 공개 활동 기준을 유지한다. 추천 순서 자체로 추측할 가능성을 완전히 제거한다는 의미는 아니며, 익명 신원을 연결하는 설명·배지·링크는 제공하지 않는다.

## 마이그레이션과 검증

V13은 content_revisions를 300자로 확장하고 승인한 층수 힌트, 순위 인덱스, `tap_record_lock`, `tap_record_achievements`를 추가한다. 기존 active VALID 시도를 제출 시각·ID 순으로 비교하여 확인 가능한 기록 갱신 권한만 복원한다. 소감·가상 참가·완료 기록을 만들지 않는다. V1~V12는 수정하지 않는다. V14에서 본문을 400자로 추가 확장하고 F 위치를 19층과 20층 사이 계단으로 변경한다. 적용된 V13은 수정하지 않는다.

`DirectPublicationResetIntegrationTest`는 실제 MySQL/Redis에서 400자/익명 전환/댓글 제한, 상위 10명/본인 순위, 동시 동점, 소감 멱등·소유권·마감, 초기화 경합과 HTTP 세션/해금/CSRF/회차를 확인한다. `check-game-rules-ui.mjs`는 운영 빌드의 격리 API 대역으로 다섯 폭의 화면·프로필·공개 링크·소감 장애 복구를 확인한다. 관리자 미리보기는 실제 컴포넌트와 메모리 순위를 사용하며 공식 API에 기록하지 않는다.

V20은 `tap_message_permissions`를 추가하고 기존 갱신자의 권한·소감을 복사한다. 갱신 이력과 한마디 권한을 분리하며 현재 슬롯·VALID·완료 근거·공개 조건을 통과한 상위 10위 진입만 새 권한을 만든다. 확정/조회/작성은 사용자 → 전역 TAP 잠금 순서를 유지한다. TAP 제출과 순위 트랜잭션만 READ_COMMITTED로 설정하여 직전 확정 기록을 보고 다른 사용자 행을 잠그지 않는다. GET 순위는 실제 방문이나 게임 결과를 생성하지 않지만 본인의 10위 진입 권한을 멱등 저장한다. 이전 회차 권한은 보관되며 새 회차로 이어지지 않는다.

참가자 UI는 공식 도전 전과 연습·준비·플레이 중 순위를 조회하거나 표시하지 않는다. 종료 후 상위 10명과 본인 순위를 표시한다. 일반 기록 재조회 버튼은 제거하고 첫 조회 실패·기존 REVIEW_REQUIRED의 복구 동작만 남긴다. 순위 새로고침·동일 기록 재전송은 유지한다. 게임 영역에 touch-action:none을 적용하고 실행 중에만 페이지 위치를 고정한다. 종료 시 스크롤을 복원하며 일반 화면의 확대·스크롤은 유지한다.
