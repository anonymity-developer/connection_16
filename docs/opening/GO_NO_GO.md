# 행사 오픈 GO/NO-GO — 2026-11-09 KST

**현재 판정: NO_GO_PENDING_EVIDENCE / 실환경 NOT_VERIFIED.** Work가 운영 DB/계정/MM/실기기에 접근하지 않았다는 뜻이다. 실제 운영 설정이 없다고 단정한 판정도, 운영 안정성 입증도 아니다. 오늘 사용자에게 실행을 요청하거나 기다리지 않고 가능한 코드·도구 검증을 완료했다.

| 상태 | 의미 |
| --- | --- |
| READY | 해당 검사 범위의 필수 조건 확인. 오프라인 메타데이터/fixture라면 그 범위만 의미 |
| BLOCKED | 제공된 설정 자료/선택한 loopback 공개 GET에서 필수 누락·오류 확인 |
| NEEDS_APPROVAL | 운영자 결정·개인정보 안내·외부 권한 승인 필요 |
| NOT_VERIFIED | 실제 환경/설정 자료/실기기 확인 못 함 |

자동 도구는 공식 GO를 발급하지 않는다. 전체 우선순위는 BLOCKED → NOT_VERIFIED → NEEDS_APPROVAL → READY이며, 별도로 항상 automaticGo=false다. GO는 아래 증거와 승인 사항을 운영자가 확인해 결정한다. 실제 운영에 적용된 정책·문항이 테스트 fixture와 같다고 가정하지 않는다.

## 오픈 차단 요인

- [ ] 실제 일정: OPEN 시작 < 신규 제출 마감 <= 검수 마감, game_duration=10, settings_version>0. DATETIME(6)은 UTC. KST=UTC+9이며 00:00:00.000001 경계도 보존.
- [ ] 현재 두 정책 포인터/승인된 버전/비공백 제목·본문. 서버는 현재 버전의 미동의를 차단하며 과거 버전 동의로 우회하지 않음. 빈 본문까지 서버가 준비 상태로 판단할 수 있으므로 도구 검사와 운영 승인이 필요.
- [ ] **가입 전 개인정보 안내 누락**: 기존 AuthService는 가입/인증 과정에서 MM 신원 정보를 사용·저장하며 현재 공개 정책 endpoint는 가입 후다. 승인된 가입 전 안내·동의 범위 및 필요한 서버 계약 설계가 아직 별도 결정 대상. 프론트 체크 추가로 대체하지 않음. [기존 P0 검토](../readiness/OPERATIONS.md) 참조.
- [ ] 운영 SYNC 설문 포인터·정의·버전 및 문항/유형 승인. 기존 예시 JSON은 검토용 초안이며 운영 확정 증거가 아님.
- [ ] 정확히 5개 활성 미션, 나머지4개 각 활성 태그>=1. 저장 해시 형식·중복 통계 검사. SHOW ME는 태그 대상 아님.
- [ ] 실제 auth/config available=true와 전용 발신 계정 승인. PAT와 계정 방식은 한 가지, 채널 ID와 팀/채널명도 한 가지 완전 설정. 자격증명/HMAC 원문을 점검 자료에 복사하지 않음.
- [ ] MM 채널 구성원 조회·DM 권한 및 자기 테스트 수신 계정 분리. 발신자 본인에게 OTP DM 불가. 실제 로그인/발송은 이번 Work에서 하지 않음.
- [ ] 실제 ADMIN 계정·검수 담당자·검수 마감 운영. 제공자 미설정/실패는 REVIEW_REQUIRED 수동 검수 경로이며 무조건 자동 승인 아님.
- [ ] 실제 가상 참가자 리허설 증거: 프로필 S 자동 지급/사전 등록 OPEN 후 재평가, SYNC/소원/공식게임/독립응원, 검수 후 A/Y, 수집판·최종 완료·관리자/일반 계정 차단.

운 점수/낙하 구역은 **선택 설정**이다. 0개 설정은 그 자체로 오픈 차단 아님. 점수 없는 슬롯을 가짜 점수로 표시하거나 나중에 설정했다고 기존 슬롯을 다시 추첨하지 않는다.
