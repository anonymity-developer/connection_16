# 네 미션 수동 검수

실제 계정/DM/운영 DB 대신 기존 fixture 브라우저 검사와 Testcontainers를 우선 사용한다. 이번 Work에서는 아래 실렌더·서버 동작을 PASS 처리하지 않았다.

| 대상 | 확인 |
| --- | --- |
| SHOW ME 불충족 | 닉네임만/소개만/관심사만일 때 프로필 저장은 기존 규칙대로, S는 미지급. MM 정보·현재 동의 누락도 차단 |
| SHOW ME 완성 | NFC 없이 프로필 저장 후 실제 서버 COMPLETED/증거 1개. 선택 URL 없이도 가능. 반복 저장·새로고침·로그인·병렬 재확인 시 중복 지급 없음 |
| 사전 등록 | preparation=false이면 행사 전 저장 차단. true이면 저장되지만 미지급. OPEN 후 접속 시 재확인 POST→GET으로 지급 확인. 시각 소급 없음. CLOSED/NOT_CONFIGURED이면 신규 지급 없음 |
| 권한/CSRF | 재확인 익명 401, 로그인했어도 CSRF 누락 403. 오래된 principal/다른 사용자 id 주입으로 지급 불가. 네 NFC 미션은 태그 전 계속 LOCKED |
| SYNC ME | 문항 미설정 안내, 필수 답/버전/최초 결과 유지. 결과의 CTA가 추천 탭으로 연결되고 실제 추천 이유/없음/오류/재시도 표시. 그래프 탭과 혼동하지 않기 |
| 소원 성공 | 접수된 뒤에만 퐁당!→검수 대기. A 미획득, 승인 전 공개/점수 미노출. 새로고침은 연출 없이 기존 슬롯 복원 |
| 소원 실패·재시도 | 400/네트워크 실패에 성공 연출 없음. 불확실 응답 재시도는 같은 key/payload. 빠른 중복 클릭/수정/거절 후 재검수도 같은 슬롯. 같은 revision 응답 중복 연출 없음 |
| 소원 운 점수 | 설정 없음이면 null 유지. 설정 있는 신규 slot에서만 최초 생성, 수정·새로고침으로 바뀌지 않음. 승인 전 score/zone 숨김 |
| SAY 파이팅! | 홈·상세·수집판 접근성 이름과 문구 일치. URL say-something/Y/독립 응원 작성→검수→공개→Y·하트 동작 유지. 소원 댓글과 구분 |
| 화면 | 360/375/390/412/430/1440px. 말풍선·수집판·상태 라벨·동전 잘림/가로 스크롤, CTA 44px, 키보드 포커스, 입력창/하단 내비 겹침. reduced-motion에서 움직임 제거 및 접수 텍스트 유지 |

SHOW ME 지급은 서버 기록만 기준으로 확인한다. 입력 체크만 보고 지급 완료라고 판단하지 않는다. 실제 기기 검수는 승인된 별도 테스트 환경/본인 테스트 계정으로 사용자가 수행한다. 이 가이드는 실제 운영 계정/데이터에 대한 자동 실행 명령이 아니다.
