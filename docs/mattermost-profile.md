# Mattermost 프로필과 가입 계약

2026-11-12 현재 계약: 한 줄 소개는 필수(200자 이내)이며 관심 산업 1~3개·개발 분야 1~3개를 선택한다. V16은 이름이 같은 기존 관심사 ID/선택을 유지하고 나머지를 LEGACY/비활성으로 보관한다. V17은 기술 스택 50개를 비활성화하고 기존 선택 행은 보존한다. 활성 선택지는 산업 10개·개발 분야 12개다. 목록·추천·그래프에 한 줄 소개와 분류 정보를 공개하고 이름·반·사진·외부 링크는 프로필 상세에서만 공개한다. 기존 사용자는 프로필을 보완한 후 동료 찾기를 이용하며 기존 글자·참여 기록은 삭제하지 않는다. [현재 추천·노출·공개 경계](recommendation-design.md). 아래 이전 필수/선택 규칙과 충돌하면 이 현재 계약을 따른다.

2026-11-05 변경 기준. 이름 직접 입력·서울 고정·소개/관심사 필수·프로필 비공개/철회 UI를 대체한다. 프로필 공개 범위 변경이며 익명 소원/응원/댓글의 기존 작성자 표시 규칙은 유지한다. 신고와 외부 자동 검수 제공자 연결은 후순위다. 관리자 수동 검수·승인 전 비공개 원칙은 유지한다.

## 가입과 입력값

1. Mattermost username으로 가입용 숫자 6자리 DM 코드를 받는다. 코드와 새 TAG ME 비밀번호를 제출해 소유·채널 참여를 확인한다. 코드 요청만으로 타인의 이름·사진을 반환하지 않는다.
2. 서버가 Mattermost 이름·지역·반과 사진 버전을 저장하고 가입 세션을 만든다. 미완성 프로필은 `/me/profile`로 이동한다. 이때부터 닉네임과 선택 항목을 입력한다.
3. 가져온 이름/지역/반/사진을 읽기 전용으로 보여준다. 닉네임은 필수, 나머지 입력은 선택이다. 공개 범위와 현재 두 정책을 한 번의 체크로 확인하고 저장한다.
4. 프로필이 먼저 완성돼도 SHOW ME 태그를 해금하기 전에는 글자를 지급하지 않는다. 기존 잠금/접수/완료 경로를 그대로 사용한다.

| 항목 | 출처와 제한 | 목록·추천 | 열린 상세 |
| --- | --- | --- | --- |
| 로그인 아이디 | Mattermost username. TAG ME 비밀번호 사용 | 숨김 | 숨김 |
| 이름·지역·반 | Mattermost 이름의 `이름[지역_반]` 파싱 | 숨김 | 표시 |
| 프로필 사진 | Mattermost 사진, 서버 경유 | 숨김·닉네임 첫 글자 | 표시, 없거나 실패하면 첫 글자 |
| 닉네임 | TAG ME 필수 입력, 최대 30 UTF-16 단위, 중복 허용 | 표시·클릭 진입 | 표시 |
| 관심사 | 산업·개발 분야 각각 1~3개 필수, 활성 카탈로그만 선택, 중복 금지 | 표시·추천 근거 | 표시 |
| 한 줄 소개 | 선택, 최대 200 UTF-16 단위 | 숨김 | 작성한 경우 표시 |
| GitHub/블로그 | 선택, HTTPS, 각 최대 2048 UTF-16 단위 | 숨김 | 작성한 경우 표시 |

가입 안내: “목록에는 닉네임이 표시되며, 닉네임을 누르면 이름·지역·반·사진과 작성한 소개·관심사·링크가 참여자에게 공개돼요.”

필수는 닉네임과 참여 안내 확인이다. 선택 항목을 비워도 저장/탐색/SHOW ME를 막지 않는다. 이름·사진 등 가져온 필드와 `isPublic`을 저장 본문에 받지 않는다. 알 수 없는 필드는 400이다. 미제공 소개/링크는 null 또는 빈 값이고 관심사는 빈 배열이다. 비밀번호·OTP·내부 Mattermost ID는 상세 공개 항목이 아니다.

## Mattermost 필드와 파싱

외부 불변 `id`는 계정 연결 키, `username`은 로그인 아이디다. 이름 후보는 `last_name + first_name`, `first_name + 공백 + last_name`, `first_name`, `last_name` 순서이며 전체 형식에 맞는 첫 값을 사용한다. 없으면 Mattermost `nickname`을 같은 형식으로 검사한다. 이 fallback은 이름 소스용이며 TAG ME 닉네임을 자동 입력하지 않는다. 실서버의 실제 필드 배치는 운영 확인이 필요하다.

이름은 공백 제거 후 1~100자, 제어문자 금지. 지역은 한글 2~10자, 반은 1~4자리 양수(1~9999)이며 뒤의 `반`은 선택이다. 예시 `홍길동[서울_09반]`은 이름 홍길동/지역 서울/반 9다. 대괄호 앞뒤 공백은 허용한다. 지역을 서울로 덮어쓰거나 없을 때 임의 반을 넣지 않는다. 서울 행사 참여 범위는 지정 채널 멤버십으로 확인하며 표시 이름만으로 권한/소속을 확정하지 않는다. 가져온 값은 독립적으로 검증한 법적 실명이 아니다.

잘못된 형식이면 가입/로그인·비밀번호 작업은 409 `MATTERMOST_PROFILE_INVALID`로 보류한다. 원본 이름을 수정하고 인증을 다시 진행한다. OTP proof를 이미 소비했다면 새 코드를 받아야 한다. 이전 계정의 가져오기 기록이 없으면 프로필 저장은 409 `MATTERMOST_PROFILE_REQUIRED`이며 재로그인 안내를 보여준다. 일반 조회만으로 원본 개인정보를 새로 가져오지 않는다.

가입/정상 로그인/비밀번호 변경·재설정 성공 때 소스를 갱신한다. 수정한 TAG ME 닉네임/소개/관심사/링크는 보존한다. 가져온 정보가 바뀌면 기존 profile.version을 증가시켜 다른 탭의 저장이 409 PROFILE_CHANGED로 재조회하도록 한다. 소스 동기화만으로 새 미션 접수나 최초 완료 시각을 만들지 않는다.

## 사진 전달과 상세 경계

`last_picture_update > 0`이면 자체 API URL을 응답한다. 브라우저에 Mattermost 토큰/외부 ID/직접 사진 URL을 보내지 않는다. 원본 이미지는 DB에 저장하지 않고 서버가 필요할 때 조회한다.

- 본인: 세션이 있는 `GET /api/v1/users/me/photo`.
- 다른 참여자: OPEN 기간에 CSRF POST `/api/v1/discovery/profiles/{id}/open`으로 상세를 연 뒤 `GET /api/v1/discovery/profiles/{id}/photo`. 사진 GET은 방문을 만들지 않는다. 미방문 대상은 404다.
- 상세·사진 모두 ACTIVE, 가져오기 완료, 닉네임/이름/지역/반, 현재 두 정책을 검사한다. 사진을 받는 동안 상태가 바뀌면 반환 전 재검사한다. 관련 사용자 잠금은 ID 오름차순, 외부 통신은 트랜잭션 밖이다.
- 외부 요청은 고정 Mattermost 서버와 검증된 사용자 ID로만 만들며 리다이렉트를 따르지 않는다. PNG MIME/시그니처, 최대 1MiB, 기존 3초 타임아웃을 적용한다. HTML/SVG/과대 응답은 전달하지 않는다. 사용자별 분당 60회 제한, no-store/nosniff다.
- 사진 미설정/오류 시 닉네임 첫 글자를 사용한다. 가짜 사진이나 외부 임의 URL을 사용하지 않는다. `v`는 소스 변경 시 브라우저 재요청을 위한 버전이며 권한 증명이 아니다.

목록·추천·그래프·공개 글에는 닉네임과 허용된 관심사/성향만 포함한다. 상세에서만 가져온 신상/사진과 입력한 소개/링크를 보여준다. 다른 참여자의 로그인 username은 상세에 포함하지 않는다. 기존 익명 콘텐츠의 profileId 제한을 지킨다. OPEN 종료 후 상세 열람 유지 정책은 별도 확정 전까지 기존 제한을 유지한다.

## 정책·이전 데이터와 변경 범위

화면에는 비공개 스위치나 동의 철회 버튼이 없다. `/users/me/consents/{type}` 변경 API도 제거했다. PARTICIPATION과 PROFILE_PUBLICATION의 버전/원문 이력은 내부적으로 유지하되 한 확인 동작으로 저장한다. 두 현재 정책이 미설정이면 저장을 차단하고 정책 교체 시 다시 확인한다. 운영자는 변경된 수집·공개 항목/보관 기간/문의 방법에 맞는 실제 문구를 확정해야 한다.

V9는 users의 동기화 시각/사진 버전과 interests.category(DOMAIN/TECH_STACK)를 추가한다. V1~V8은 수정하지 않는다. 기존 is_public은 레거시 호환용 내부 컬럼이며 유효한 새 프로필 저장은 항상 true다. 과거 비공개/미완성 계정을 마이그레이션으로 일괄 재공개하지 않는다. 기존 계정은 재로그인→가져온 정보 확인→현재 안내 확인·저장으로 전환한다. 정지/탈퇴/동의 미달 계정의 공개 제한과 과거 방문 이력 보존은 유지한다. 개인정보 삭제/문의의 실제 운영 절차는 비공개 토글과 별개로 확정해야 한다.

정확한 응답은 [참여 OpenAPI](participation.openapi.yaml)와 [탐색 OpenAPI](discovery.openapi.yaml), 인증은 [인증 계약](auth.md)을 따른다. 참고한 공식 API는 [사용자 필드](https://docs.mattermost.com/api/reference/get-users)와 [사용자 API](https://docs.mattermost.com/api/reference/users)다. 자동 검사의 Mattermost 응답은 대역이며 실제 필드 배치·지정 채널/DM·사진 조회 권한·실기기 검증 완료를 뜻하지 않는다.
