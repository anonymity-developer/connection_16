# 3차 TAG ME UI - 밝고 친근한 이벤트 리디자인

상태: **구현 완료·검토/적용 대기**. 2차 `TAGME_ssafy_ui_integrated_86ad1dd.zip`을 기준 커밋의 별도 worktree에 먼저 적용한 후 작업했다. 이전 ZIP과 작업 공간은 그대로 보존했다. commit/push/PR/merge/배포·실서버 접속 없음.

## 바뀐 인상

- 홈: 이어진 두 태그의 작은 SVG(공식 로고 아님), 반가운 인사, 점선 테두리 수집 보드. 미획득은 회색, 완료한 글자는 미션별 파스텔 스티커로 표시한다.
- 미션: 일괄 관리 목록 대신 개별 둥근 카드, 글자 스티커와 기존 미션 아이콘 조합. 블루/민트/옅은 옐로우/라일락으로 미션의 개성을 표현한다. 모바일은 한 열이며 다섯 번째 카드는 데스크톱에서 전체 폭을 사용한다.
- 인증: 기존 입력·버튼·단계·남은 시간·재발송·오류는 유지하고, 참여 시작 문구와 연결 태그 그림을 더했다. 비밀번호 안내와 MM/TAG ME 구분은 유지한다.
- SHOW ME: 목표 S를 붙인 첫 글자 미션, 흰 체크리스트와 준비된 항목의 민트 표시. 입력 미리보기와 서버의 지급 완료 상태를 계속 구분한다.
- 동료 찾기/그래프/프로필: 말풍선처럼 부드러운 이니셜, 작은 파스텔 표식, 소개 카드/명함 느낌. 그래프의 선 너비·좌표·방향·노드 링크와 공개 범위는 그대로다.
- 태그: 연결 태그 그림과 현장감 있는 안내. 기존 주소 검증·해금·인증 후 복귀·오류 경로는 유지한다.

전체를 업무용 카드에서 밝은 행사 카드로 재해석했다. 새 패키지/새 폰트/애니메이션은 제품 코드에 추가하지 않았다. 기존 UI/CSS를 보존하고 마지막에 `friendly.css`를 불러와 적용한다. 민트·라일락·옐로우·둥근 배지·부드러운 그림자는 사용자가 이번에 명시한 방향이며 기존 정적 디자인 검사 취향과 다른 부분은 의도된 선택이다. 관리자 경로에는 적용하지 않는다.

## 참고 근거

05-pjt의 확인 가능한 코드/파일을 제목 검색으로 찾지 못했다. 제공된 참고 이미지 `01_입력검증.png`는 화면에 **SSAFY 07 PROJECT**로 표시되어 있으므로 05-pjt 구현으로 설명하지 않았다. 해당 이미지에서 확인되는 밝은 블루·둥근 패널·작은 포인트 아이콘만 참고하고, 무거운 배너/책 그림은 복제하지 않았다. 현재 TAG ME 화면 캡처 `image(20261107-095201).png`를 함께 확인했다. 공식 SSAFY 로고/색상값을 새로 만들거나 공식 자산이라고 표시하지 않았다.

## 전달과 적용

- `v3-over-stage2.patch`: 사용자가 현재 검토 worktree에 적용한 **2차 통합 UI 위에** 추가한다.
- `full-integrated-86ad1dd.patch`: 새 `86ad1dd` 작업 공간에 1~3차를 모두 적용한다.
- 두 패치는 대안이며 연속 적용하지 않는다. 원래 2차 worktree에 후속 수정이 있다면 먼저 확인하고 `git apply --check` 실패 시 강제 적용하지 않는다.
