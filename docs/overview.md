# 제품 개요

TAG ME는 SSAFY 16기 서울 캠퍼스 참가자가 현장 미션을 매개로 서로를 알아가는 모바일 웹 서비스다. 핵심 경험은 **NFC로 미션 발견 → SSAFY 글자 수집 → 동료 탐색**이다.

## 참가자 경험

- Mattermost 아이디와 TAG ME 전용 비밀번호로 로그인한다.
- 프로필에는 Mattermost의 이름·지역·반·사진을 가져오고, 닉네임·소개·관심사를 등록한다.
- SHOW ME는 완성된 프로필에서 지급한다. 나머지 네 미션은 서버가 유효한 NFC 토큰을 확인해야 열린다.
- 미션을 완료할 때마다 대응하는 글자를 받고, 다섯 글자를 모으면 완성 기록이 남는다.
- 공개 프로필과 관심사·SYNC 유형·활동을 바탕으로 동료를 추천받고, 서로의 프로필 열람 관계를 확인한다.

## 다섯 미션

| 코드 | 글자 | 기능 | 완료 기준 |
| --- | --- | --- | --- |
| `SHOW_ME` | S | 프로필 | 행사 OPEN 중 필수 프로필·현재 두 동의 저장/재평가 |
| `SYNC_ME` | S | 취향 질문 | 현재 문항 버전 최초 결과 저장 |
| `MAKE_A_WISH` | A | 소원 호수 | 1인 1소원 최초 등록 |
| `FAST_TAP` | F | 탭 게임 | 유효한 공식 도전 결과 저장 |
| `SAY_SOMETHING` | Y | 응원 게시판 | 1인 1응원 최초 등록 |

소원과 응원은 400자, 댓글은 200자까지다. 콘텐츠는 기본적으로 동기식 직접 공개되며 운영자는 별도 검수 대신 숨김·복구와 감사 이력을 관리한다. FAST TAP과 콘텐츠 수정, 익명 공개, 시상 후보의 자세한 규칙은 [미션 규칙](mission-rules.md)을 따른다.

## 공개 범위

- 목록에는 닉네임과 소개·관심사·SYNC 유형 등 네트워킹 정보가 표시된다.
- 이름·지역·반·사진·외부 링크는 인증된 참가자가 상세 프로필을 열 때만 제공한다.
- 소원·응원·댓글은 작성 시 선택한 익명/닉네임 공개 정책을 따른다. 익명 반응도 내부 추천 점수에 반영될 수 있지만 작성자 연결이나 반응 기반 추천 사유는 공개하지 않는다.
- 비밀번호, OTP, 외부 사용자 ID, 원본 NFC 토큰, 내부 추천 점수와 익명 작성자 연결은 공개하지 않는다.

## 운영자 경험

독립 `admin:` 계정은 참가자와 분리된다. 관리자는 현황·회원·미션 순위·완료 기록·콘텐츠·감사·시상 후보·행사 결과를 확인하고, 사유와 감사 기록을 남기는 지원 조치를 수행할 수 있다. 최종 수상 확정이나 임의의 운영 데이터 생성은 제공하지 않는다.

세부 화면 순서는 [유저 플로우](user-flows.md), 서버 경계는 [아키텍처](architecture.md), 현재 완료 범위는 [구현 상태](progress.md)를 참고한다.
