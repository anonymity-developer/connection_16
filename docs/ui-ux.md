# 화면 설계와 UI/UX 기준

수집 중 ‘우리를 찾아봐!’는 카드 중앙, 획득 수는 카드 밖 ‘나의 SSAFY 수집판’ 제목 오른쪽에 표시한다. 미션 카드의 글자 이미지 열은 데스크톱 64px/모바일 56px이며 설명까지 24px/20px 간격을 둔다. 가입된 계정의 코드 요청은 계정 입력 단계에 안내하며 새 비밀번호 설정에는 8~20자 정책을 사용한다.

참가자 세 주요 페이지는 ParticipantPage/ParticipantHeading을 공유한다. 동료 찾기/마이페이지의 비로그인 안내는 ParticipantSignIn을 공유하며 720px 예외 없이 같은 페이지 폭·카드·아이콘·폰트·버튼을 사용한다. 수집판 제목은 카드 밖에서 SSAFY 미션과 ParticipantSectionHeading을 공유한다. 비로그인/수집 중/완료의 안내·진행/상태·기록 영역과 미션 카드 행을 정렬하되 모르는 획득 수는 표시하지 않는다. 완료 기록은 서버의 운영 순번을 표시하며 미확정 수상 순위 안내 문장은 생략한다.

공통 참가자 헤더에 오류 신고를 제공한다. 로그인 계정이 200자까지 입력하며 관리자 오류 신고 메뉴에서 접수 내용을 확인한다. 관리자 참가자 상세에는 사유/확인 대화상자가 있는 계정 비활성화·미션별 해금/획득 조정을 제공한다. [현재 운영 지원 계약](support-and-member-controls.md).

2026-11-11 승인 UI: 홈은 ‘태그를 찾고, SSAFY를 모아요’, 로그인 안내는 ‘NFC 태그로 미션을 찾아보세요’를 사용한다. 게임 제목/소개는 한 번만 두고 참여 화면 뒤에 짧은 이벤트 팁을 둔다. 진행 현황은 상태를, 접힌 ‘미션 안내’는 위치·제한을 담당한다. SHOW ME는 태그 위치 대신 프로필 조건을 설명한다. NFC 확인 화면은 미션별 캐릭터/글자를 표시하고 소개 S·취향 S를 구분한다. 로그인 전 메타데이터 조회는 해금이 아니다. 서버의 새 완료가 확인되면 현재 화면 위에 컬러 글자 획득 대화상자를 열고 계속 참여/선택적인 수집판 이동을 제공한다. 계정·초기화 회차별 확인 상태로 재방문/수정 시 연출을 반복하지 않는다. 관리자 예시는 실제 획득 연출을 만들지 않는다.

현재 관리자 참가자 상세에는 **게임 재참여**와 확인 대화상자가 있다. 콘텐츠 기본 화면에는 검수 대기/승인 버튼이 없으며 소원·응원·댓글은 작성하면 바로 공개한다. [현재 공개·초기화 계약](direct-publication-and-reset.md).

이 문서는 전체 화면의 설계 기준이다. 일부 프론트 UI를 구현했으며 실제 범위와 검증은 [UI 검수](ui-review.md), [개발 현황](progress.md)에 기록한다. 제품의 핵심 인상은 **모바일에서 예쁘고 참여 흐름이 명확한 현장 미션 수집 경험**이다. 페이즈 1의 구체 색상/서체/선택 근거는 UI 검수 문서를 따른다.

## 1. 정보 구조와 경로 계획

현재 비로그인/로그인 동료 찾기는 같은 분류·제목·설명과 페이지 폭을 공유한다. 인증 화면은 상단의 미션 모으기/마이페이지 뒤로가기 링크를 생략하고 폼 하단 복귀 링크와 공통 내비게이션을 사용한다.

전체 수집 완료 팝업은 별도 제목 없이 “SSAFY 글자를 모두 수집했어요!”와 “N번째로 수집을 완료했어요.”를 표시한다. N은 서버가 저장한 해당 회차의 완료 순번이며 시상 순위나 프론트에서 계산한 인원수가 아니다. 확인 후 재방문 시 반복하지 않으며 순번이 아직 없거나 유효하지 않으면 임의 값을 표시하지 않는다.

아래는 프론트 라우트 제안이며 API 경로와 별개다. 태그 토큰 외 화면 경로는 쉽게 읽히는 이름을 사용한다.

| 경로 | 화면 | 접근 및 주 행동 |
| --- | --- | --- |
| `/` | 서비스 소개 또는 내 수집판 | 공개 소개, 로그인하면 진행도 |
| `/auth` | 일반 로그인 | Mattermost 아이디와 TAG ME 비밀번호, 가입/비밀번호 찾기 링크 |
| `/auth/signup` | 최초 회원가입 | Mattermost 아이디 → DM 6자리 → 서비스 비밀번호 설정 |
| `/auth/password-reset` | 비밀번호 찾기 | Mattermost 아이디 → 재설정 DM 6자리 → 새 비밀번호 |
| `/me/password` | 로그인 사용자의 비밀번호 변경 | 본인 계정 DM 6자리 확인 → 새 비밀번호 → 재로그인 |
| `/me/profile` | 최초 프로필과 참여 안내 | 가져온 정보 확인, 닉네임 필수·선택 항목·상세 공개 안내 |
| `/t/{token}` | 태그 복귀/검증 | 인증 연결, resolve, 미션으로 이동 |
| `/missions/show-me` | 프로필 미션 | 해금 확인, 프로필 완성 또는 결과 |
| `/missions/sync-me` | 성향 질문/유형 | 공식 1회, 결과 다시 보기 |
| `/missions/make-a-wish` | 소원 호수 | 내 소원, 공개 소원과 댓글 |
| `/missions/fast-tap` | 탭 게임 | 연습/공식 시작/기록 |
| `/missions/say-something` | 응원 카드 | 작성/미리보기/하트 |
| `/complete` | 다섯 글자 완성 | 서버 전체 완료 확인, 후속 활동 연결 |
| `/discovery` | 동료 탐색 | 추천/전체 탭, 닉네임 검색·관심사 필터·커서와 실제 추천 이유 |
| `/discovery/graph` | 내 발견 그래프 | 단방향/상호 발견 및 목록 대체 |
| `/discovery/profiles/{id}` | 상세 프로필 | 현재 경로 인증 확인 → CSRF POST open으로 최초 방문과 상세 반환 |
| `/me` | 내 프로필과 기록 | 프로필 수정/결과/참여 안내 확인 |
| `/admin` | 관리자 현황 | 독립 관리자 로그인 → 가입·미션·순위·전체 완료·접속 현황, 태그 없는 미리보기 |
| `/admin/moderation` | 콘텐츠 운영 | 현재 ADMIN 확인 → 검수본 비교·사유 판정/제한 재처리, 콘텐츠 숨김·복구, 감사·시상 후보·행사 결과 조회 |

모바일 기본 내비게이션은 홈 수집판/동료 탐색/내 정보로 단순화한다. 소원과 응원은 미션 화면 및 홈의 후속 활동 영역에서 다시 찾을 수 있게 한다. 게임 중에는 종료/이탈의 결과를 안내하고 브라우저 기본 뒤로가기를 임의로 무력화하지 않는다.

## 2. 디자인 시스템

| 요소 | 기준 |
| --- | --- |
| 색상 | 배경/본문/약한 텍스트/강조/성공/경고/오류/경계선의 의미 토큰으로 구분 |
| 글자 | 제목/본문/보조/숫자와 타이머의 크기 체계; 한글 줄바꿈과 숫자 폭 확인 |
| 레이아웃 | 공통 콘텐츠 폭, 간격 배수, 카드 패딩, 버튼 높이, 모서리와 그림자 규칙 |
| 입력 | 레이블, 도움말, 오류, 비활성, 포커스, 글자 수, 제출 중 상태 공통화 |
| 상태 배지 | 글자와 아이콘을 함께 제공하고 색상만으로 의미를 전달하지 않음 |
| 모션 | 해금/글자 획득/완성의 짧은 피드백, reduced-motion 대안 |
| 공통 컴포넌트 | Button, TextField, Card, MissionSlot, StatusBadge, Dialog, EmptyState, ErrorState, Toast |

디자인 토큰은 CSS 변수로 관리하고 임의의 색상/간격을 화면마다 추가하지 않는다. 미션별 배경과 일러스트의 개성을 허용하되 공통 버튼, 입력, 상태 표현은 유지한다. 구체 자산의 사용 권한을 확인하고 SSAFY 공식 서비스로 오해하게 하는 문구는 운영 승인 전 사용하지 않는다.

수집판은 미발견 시 회색 배경·회색 캐릭터, NFC 해금/진행 중에는 미션 파스텔 배경·회색 캐릭터, 완료 시 파스텔 배경·컬러 캐릭터로 구분한다. 태그가 없는 SHOW ME는 프로필 보상 조건을 충족해 완료되기 전까지 회색이다. 기록을 아직 읽지 못했거나 로그아웃한 경우에도 회색이며, 미션 소개 카드의 컬러 일러스트는 획득 기록을 뜻하지 않는다.

## 3. 핵심 화면별 구성

### 인증

일반 로그인 화면은 Mattermost 아이디/서비스 비밀번호와 로그인 버튼, 회원가입/비밀번호 찾기로 구성한다. "비밀번호는 TAG ME 가입 때 설정한 값"이라고 안내하고 일반 로그인에 OTP 입력을 요구하지 않는다. 아이디는 `autoComplete="username"`, 로그인 비밀번호는 `type="password"`, `autoComplete="current-password"`를 사용한다.

가입은 아이디/DM 발송 → 6자리 확인과 비밀번호/확인 입력 → 가입/프로필 설정이다. 비밀번호 변경은 로그인한 본인 계정으로, 분실 재설정은 입력한 아이디의 계정으로 DM을 보낸다. 각각의 purpose와 화면 제목/문구를 구분한다. 새 비밀번호 입력에는 `autoComplete="new-password"`를 쓰고 표시/숨김과 정책 오류를 안내한다. 비밀번호/확인 값은 localStorage/sessionStorage/URL에 저장하지 않는다.

DM 단계에는 숫자 6자리 입력, 남은 시간, 재발송 대기, 오류/복구 행동을 배치한다. 하나의 논리적 입력으로 붙여넣기와 포커스 이동을 안정적으로 지원한다. 여섯 칸처럼 보이게 만들더라도 스크린리더/키보드에서 하나의 코드를 이해할 수 있어야 한다. 변경/재설정이 끝나면 모든 기존 세션 종료와 재로그인을 안내한다.

`type="text"`, `inputMode="numeric"`, `autoComplete="one-time-code"`, `maxLength={6}`를 기본으로 한다. 모바일 OS의 자동완성 제공 여부에 의존하지 않고 직접 입력/붙여넣기를 지원한다. OTP와 challenge를 화면 주소에 넣지 않는다.

### 홈 수집판

상단은 내 닉네임과 행사 상태, 중심은 S/S/A/F/Y 다섯 칸, 하단은 다음 미션 힌트와 소원/응원/동료 탐색 진입으로 구성한다. 두 S에는 SHOW ME/SYNC ME 이름을 같이 표시한다. 미완료 개수와 검수 대기 개수를 구별한다. 전체 완료 순번을 최종 수상 순위처럼 표기하지 않는다.

### 프로필

목록은 닉네임/관심사/공개 가능한 성향 유형 중심이다. 상세를 열면 Mattermost 이름/지역/반/사진과 입력한 소개/관심사/외부 링크, 발견 상태를 보여준다. 링크는 새 탭 이동과 외부 서비스임을 표시한다. 가입·프로필 저장 시 상세 공개 범위를 한 줄로 안내하고 한 번 체크한다. 비공개 설정은 없다. 닉네임만 필수이며 도메인/기술 스택·소개·링크는 선택이다. 가져온 정보는 읽기 전용이다. 사진 오류는 닉네임 첫 글자로 대체한다. [가입 계약](mattermost-profile.md)을 따른다. 익명 카드/댓글에는 상세 프로필로 연결되는 조작 요소를 만들지 않는다.

### 소원 호수

소원이 함께 쌓이는 공간을 중심으로 내 소원 작성/검수 상태와 다른 소원 상세/댓글을 쉽게 찾게 한다. 장식 때문에 텍스트가 읽히지 않거나 소원을 선택하기 어렵지 않아야 한다. 구름 보기에서는 소원 내용을 텍스트로 읽고 키보드로 선택해 상세와 댓글을 열 수 있다. 운 결과는 서버 값으로 재현하고 승인 전 동전이 공개된 것처럼 보이지 않게 한다.

### 성향 테스트와 결과

문항 진행도, 이전 선택 복귀, 선택 상태, 제출 확인을 제공한다. 결과는 유형 이름/한 줄 설명/축별 특징/동료 탐색 연결로 구성한다. 문항 수와 유형은 확정 전 숫자를 하드코딩하지 않는다. 공식 결과 확정 후에는 다시 보기 중심으로 제공한다.

### FAST TAP

공식 1회 안내와 연습 버튼을 먼저 보여준다. 연습과 공식 모드는 제목/색상/버튼으로 명확히 구별한다. 카운트다운 5초, 플레이 10초, 남은 시간과 현재 탭 수를 크게 표시한다. 탭 영역만 `touch-action: none`, `user-select: none`을 적용하고 페이지 전체 확대/탐색을 불필요하게 막지 않는다. 결과는 유효/검토/무효를 구별한다.

### 응원 카드

작성 → 템플릿/허용 스타일 선택 → 익명 여부 확인 → 미리보기 → 제출 순서다. 승인본과 수정 대기본은 시각적으로 구별한다. 하트는 처리 중 중복 클릭을 막고 실패하면 서버 상태로 복구한다. 모바일 카드 목록에서 문구가 잘리지 않도록 전체 보기 경로를 둔다.

### 발견 그래프

나를 중심으로 방문 관계를 보여주고 단방향/상호 방문을 범례와 문구로 구별한다. 노드 터치로 상세를 열되 작은 화면의 확대/이동과 충돌하지 않게 한다. 그래프와 동일한 사람 목록/발견 통계를 함께 제공한다. 자격을 잃은 노드는 재조회 후 제거하며 타인의 전체 관계를 펼치는 기능은 초기 범위에 넣지 않는다.

## 4. 상태별 표현과 오류 복구

| 상태 | 화면 표현 | 행동 |
| --- | --- | --- |
| 미인증 | 로그인 필요와 원래 진입 안내 | 인증 후 복귀 |
| 미해금 | 잠금과 해당 태그 힌트 | 현장 태그 찾기, 홈 복귀 |
| 해금/진행 | 수행 버튼과 저장된 진행도 | 계속하기 |
| 제출 중 | 버튼 중복 방지와 처리 안내 | 응답 유실 시 현재 상태 조회 |
| 검수 대기 | 접수 완료, 아직 글자 미획득 | 상태 다시 확인, 다른 활동 |
| 거절 | 수정 가능한 이유와 입력 보존 | 같은 슬롯의 새 revision 작성 |
| 완료 | 저장된 결과와 획득 글자 | 다시 보기/후속 활동 |
| 비공개/없음 | 대상에 접근할 수 없음 | 목록 갱신 |
| 행사 마감 | 신규 참여 마감과 기존 결과 안내 | 허용된 조회만 제공 |
| 서비스 장애 | 재시도 가능한 안내 | 복구 후 서버 상태 재조회 |

서버가 계산한 상태를 표시하고 애니메이션 종료나 localStorage 값으로 미션을 완료하지 않는다. 검수 대기 안내에 확정되지 않은 예상 시간을 약속하지 않는다. 토스트만으로 오류를 알리지 않고 해당 입력/화면에도 설명을 남긴다.

## 5. 검증과 개발 순서

1. 공통 토큰과 버튼/입력/카드를 만든다.
2. 실제 모바일 크기로 인증, 수집판, 대표 미션, 글자 획득 화면과 실패 상태를 구성한다.
3. 서버 계약에 맞춰 인증과 수집판을 연결한다. 화면 확인용 fixture는 개발 모드에만 두고 인증 우회 API를 만들지 않는다.
4. 개별 미션, 검수 대기/수정, 탐색/그래프와 관리자 화면을 확장한다.
5. iOS Safari/Android Chrome 실기기로 전체 참여 경로를 검증한다.

360/390/430 CSS px에서 가로 넘침, 한글 긴 닉네임, 긴 소원, 키보드, safe area, 네트워크 대기를 확인한다. 주요 터치 영역은 최소 44×44 CSS px로 잡는다. 모션 감소, 키보드 포커스, 레이블과 목록 대체 보기를 확인한다. UI 완료와 서버 기능 완료를 각각 기록한다.

## 페이즈 5-1 현재 화면 경계

[탐색 계약](discovery.md)을 따른다. 서버는 유형 코드/문항 버전 필터도 지원하지만 현재 화면 필터는 닉네임/관심사다. 통계는 내가 본 동료/나를 본 동료/서로 본 동료의 전체 적격 수이고, 실제 관계 그림은 8명/목록은 30명까지다. 데스크톱에서 관계 그림과 명단을 나란히 두고 모바일은 세로 흐름을 유지한다. 실명/반은 목록에서 숨기며 프로필 상세 성공에서만 보인다. Mattermost 가져오기/선택 입력 안내, 실제 빈 상태와 오류/재시도를 제공한다. 개인별 차단/관리자 화면은 아직 없다.

## 2026-11-12 승인한 미션 화면

소개·이름은 상단, 참여 화면/참여 후 본인 기록은 중앙에 표시한다. 기존 이벤트 팁은 미션 안내의 TIP 항목에서 확인한다. 획득/미획득 상태는 나의 진행 현황의 글자 이미지 옆에 둔다. SHOW ME는 실제 내 프로필, FAST TAP은 본인 기록·상위 10명·갱신 소감을 표시한다. 층수·300자·익명/공개 선택 등 현재 안내와 장애 복구 계약은 [확정 규칙](mission-rules.md)을 따른다.

미션 모으기·동료 찾기·마이페이지 상단은 같은 `page-heading` 구조로 분류 문구 → 페이지 제목 → 설명을 표시한다. 미션 모으기는 `TAG ME 미션 / 미션 모으기`와 기존 NFC 설명을 사용하며 별도 배너 장식/위 여백/제목 크기를 적용하지 않는다. 수집판 내부의 글자·장식은 유지한다.

로그인·회원가입·비밀번호 변경·재설정은 마이페이지와 같은 페이지/카드 폭을 사용한다. 900px 이하에서는 전체 너비의 한 열로 쌓으며 인증 폼만 460px로 제한하지 않는다. 마이페이지의 수동 태그 이어가기 버튼·도움말은 제거하고 로그인/가입 후 원래 NFC 미션 복귀는 유지한다. 비밀번호 변경은 이전 페이지의 전역 알림을 정리하고 자체 안내만 표시한다. 변경 완료 후 로그인 화면의 세션 종료/재로그인 안내는 유지한다.

마이페이지 주 카드와 네 인증 폼 카드는 같은 내부 여백과 모서리 스타일을 공유한다. 로그아웃·회원가입 연결·로그인 복귀·변경 취소는 `account-card-footer`로 카드 하단 가운데에 배치하고 앞 동작과 20px 간격, 최소 48px 조작 높이를 유지한다. 로그아웃은 프로필/비밀번호의 주요 버튼 묶음과 분리한다.
