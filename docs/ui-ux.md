# 화면 구조와 UI 기준

현재 화면 흐름은 [유저 플로우](user-flows.md), 기능 규칙은 [제품 개요](overview.md)와 각 도메인 계약을 따른다. 이 문서는 화면에 공통으로 적용하는 기준만 다룬다.

- 수집판·동료 찾기·마이페이지는 공통 참가자 페이지 폭과 제목 형식을 사용한다. 모바일 하단 내비게이션과 PC 상단 내비게이션은 같은 세 영역으로 연결된다.
- 인증 화면도 공통 페이지/카드 스타일을 사용한다. 가입·비밀번호 변경·재설정은 계정 확인 후 DM 인증 단계로 이동한다.
- 다섯 미션은 캐릭터·제목·소개, 게임 영역, 진행 현황·접힌 미션 안내를 공유한다. PC는 게임과 300px 진행 패널, 좁은 화면은 세로 배치다. 획득 여부는 진행 현황의 글자 옆에 표시한다.
- 수집판 제목과 획득 수는 판 위의 한 행에, ‘우리를 찾아봐!’는 판 중앙에 둔다. 비로그인·진행·완료 상태에서 구조를 유지한다.
- 글자 획득은 서버 완료를 확인한 뒤 연출하며 현재 미션에 머문다. 다섯 글자 완료 안내의 순번은 서버의 운영상 완료 순서다.
- 소원은 호수·목록·공통 상세/댓글, 응원은 색상칩·익명 체크박스·한 열 카드와 더 보기, FAST TAP은 준비·플레이·결과로 구분한다. 서버 미확정 결과를 성공처럼 표시하지 않는다.
- 관계 그래프는 방향 방문만 표현하고 노드 선택으로 소개·프로필 동선을 제공한다. 추천 점수나 익명 반응을 그래프에 표시하지 않는다.

## 확인 기준

360/390/430px와 태블릿·PC에서 가로 넘침, 조작 영역, 줄바꿈, 카드 간격, 고정 내비게이션 가림을 확인한다. 키보드 포커스·오류 안내·뒤로가기·팝업 닫기·모션 감소를 지원한다. 스크롤/확대 제한은 FAST TAP 진행 영역 등 필요한 상태에만 적용한다.

브라우저 절차는 [프론트 AGENTS](../frontend/AGENTS.md)와 [Codex 셋업](codex-setup.md)을 따른다. README 화면은 합성 데이터이며 운영 참가자의 캡처를 사용하지 않는다.
