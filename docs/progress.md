# 현재 구현 상태

기준: `main` / 2026-11-16. 이 문서는 과거 작업일지가 아니라 현재 제공되는 기능과 남은 운영 확인만 기록한다.

## 구현 완료

- Mattermost 계정 확인, 가입·변경·재설정용 6자리 DM OTP, TAG ME 비밀번호 로그인과 Redis 세션
- 독립 `admin:` 운영자 로그인과 현재 DB 역할 재검증
- Mattermost 기본 정보 가져오기, 닉네임·소개·산업/개발 관심사 프로필
- 행사 상태·참여 동의, SHOW ME 자동 지급, 네 NFC 미션 해금과 SSAFY 수집판
- 한 문항씩 진행하는 9문항 SYNC, 8개 결과 캐릭터와 같은 버전·같은 유형 동료 목록
- 공식 FAST TAP, 상태 판정, 상위 10명 순위와 1회 소감
- 종이배 소원 호수, 소원 목록·상세·댓글·이전/다음 탐색, 첫 등록 연출
- 응원 게시판, 10색·익명/닉네임 선택, 20개 커서 조회·작성/하트 정렬과 즉시 하트
- 관심사·성향·활동 기반 동료 추천, 전체 검색, 공개 상세와 방향 방문 관계
- 콘텐츠 직접 공개, 운영자 숨김/복구, 감사 이력
- 회원·미션·완료·순위·시상 후보·행사 결과·오류 신고 관리자 화면
- 참가자 비활성화/연결 해제, 미션 조정, 게임 초기화와 generation 기반 오래된 요청 차단
- 로컬 전용 합성 fixture와 운영 빌드 분리
- Docker Compose, GitHub Actions 검사, Sydney EC2/Caddy 배포 흐름

## 현재 정책

- 기본 콘텐츠 정책은 검수 대기가 아닌 동기식 직접 공개다.
- SHOW ME는 NFC가 아니라 완성된 프로필·참여 조건으로 지급한다.
- 나머지 네 미션은 서버에서 유효한 NFC 해금을 확인한다.
- 운영상 전체 완료 순서와 최종 시상 순위는 별개다.
- 추천은 weighted-v4 가산점과 미열람 노출 최대 20점 감점을 사용하며 최대 12명을 반환한다. 익명 연결·내부 점수·익명 반응 기반 이유는 공개하지 않는다. 공통 관심사·유형·방문 여부는 공개 범위에서 안내한다.
- 관리자 지원 조치는 근거를 위조하지 않고 `ADMIN_ADJUSTMENT`와 감사 이력을 남긴다.

## 배포 전·현장 확인

- 실제 Mattermost DM 권한과 발신 계정 상태
- 실물 NFC, iOS·Android 기기, 행사장 네트워크의 전체 여정
- 행사 개장·마감 시각과 현재 동의/문항 설정
- 운영 백업의 서버 외부 암호화 보관 및 복원 연습
- 예상 참가자 규모의 부하와 장애 복구
- 최종 수상자 확정·중복 수상·발표 절차

인프라 역할과 저장/재시작 경계는 [서버·DB·Redis 안내](infrastructure.md)를 따른다. 구체 실행은 [개발 가이드](development.md), 현장 점검은 [행사 운영](operations.md), 배포 상태는 [운영 배포](github-actions-ec2.md)를 따른다.
