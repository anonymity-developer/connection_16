- 기존 PR #23에서 후속을 진행했다. 이미 비밀번호가 있는 ACTIVE Mattermost 계정은 SIGN_UP 코드 요청 시 409 ACCOUNT_ALREADY_REGISTERED로 안내하고 DM/인증번호·비밀번호 단계로 넘어가지 않는다. 기존 legacy 무자격증명 최초 가입과 비활성화 후 새 가입은 유지하고, 최종 가입 경합도 기존 비밀번호를 덮어쓰지 않는다. 로그인 전 가입 존재가 드러나는 사용자 승인 UX 선택이며 기존 계정/외부 ID/IP 요청 제한과 로그인·재설정의 일반 응답을 유지한다.
- 새 참가자 비밀번호는 가입/변경/분실 재설정 모두 공백 포함 8~20 Unicode code point로 서버·클라이언트·안내·OpenAPI를 맞췄다. 문자 자르기/정규화를 하지 않고 기존 긴 비밀번호 로그인과 관리자 bootstrap 15~64자 정책을 유지한다. 브라우저 검사 대역의 정책도 새 계약으로 갱신했다.
