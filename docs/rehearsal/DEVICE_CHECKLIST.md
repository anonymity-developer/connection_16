# 실제 화면·기기 확인

기존 production build와 fixture 계약 검사를 우선 사용한다. 실제 계정/DM/운영 데이터로 자동 테스트하지 않는다.

- [ ] 360/375/390/412/430/1440px에서 가로 스크롤 없음. 수집판 다섯 캐릭터·미획득 말풍선·슬롯 라벨·하단 고정 내비/푸터가 겹치지 않음
- [ ] 전체 획득이면 말풍선 제거·서버 완료 글자만 컬러. 검수 대기는 획득으로 보이지 않음
- [ ] SHOW ME는 프로필·동의로 안내. 나머지 네 미션은 태그 전 본문 수행 차단. 로그인/가입 후 읽어 둔 태그 미션으로 복귀
- [ ] iPhone Safari/Android Chrome에서 NFC/QR → 로그인 → 뒤로가기/새로고침/재접속. 앱 내 브라우저와 일반 브라우저 세션 차이 안내 확인
- [ ] 폼 키보드가 필수 입력·오류·제출 버튼을 가리지 않음. 6자리 OTP 선행 0·붙여넣기와 닉네임/소개/관심사·동의 팝업 포커스 확인
- [ ] SYNC 선택지 터치·필수 응답/오류/최초 결과·추천 CTA·추천 없음·재조회 가능
- [ ] 소원 실패에는 성공 동전 없음. 정상 접수 후 짧은 동전·물결 및 검수 안내. reduced-motion에서 정적 표시. 재조회는 연출 재생 없이 기존 slot
- [ ] FAST TAP 실제 5초/10초 터치·키보드·버튼 크기. 화면 이탈·백그라운드·새로고침/단절 후 서버 기록 복원·명시적 재시도. 임의 공식 기회 재발급 없음
- [ ] 두 탭에서 취소→새 도전 경합 후 오래된 취소 응답이 새 slot을 가리지 않음
- [ ] SAY 파이팅!의 익명/닉네임·승인본/수정본, 하트 취소·반복, 소원 댓글과 분리
- [ ] 관리자 권한 없는 계정은 검수/시상 데이터 없음. 후보 목록 빈/로딩/오류/공동 순위·중복 후보·근거 펼치기와 페이지 이동
- [ ] Tab/Enter/Escape/포커스 복귀·터치 영역·대비·긴 문구 줄바꿈. 실제 브라우저 실렌더 PASS는 직접 확인한 폭/기기만 기록
- [ ] 격리 환경에서 앱 프로세스 재시작 후 프로필/5개 evidence/완성 순번/공식 slot/승인본 보존. 운영 데이터·볼륨은 건드리지 않기

정책/일정이 아직 미설정이면 실제 화면 쓰기가 차단되는 것이 정상이다. 화면 검토를 위해 필수 동의/행사 기간/관리자 권한을 우회하지 않는다. 실물 NFC의 위치는 승인된 설치 안내만 사용하고 전체 URL·토큰을 보고서/스크린샷에 담지 않는다.
