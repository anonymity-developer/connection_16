# 행사 당일 장애 대응 / 배포 전 체크

두 운영자 역할을 사전에 나눈다: 한 명은 공지·문의/증상 수집, 한 명은 상태 확인·기술 조치. 승인 전 실제 계정/기록/행사 시간을 바꾸지 않는다.

## 장애 대응

| 증상 | 확인 순서 | 안전한 대응 / 하지 말 일 |
| --- | --- | --- |
| OTP 미수신/인증 503·429 | auth/config 활성 여부 → API/Redis health → MM 발신 계정 승인·접속/채널/DM 권한 → 제한 대기 | 숫자 코드/비밀번호/PAT/세션/실명은 수집하지 않음. 재발송 연타/실사용자 대량 조회 금지. 발신자 본인은 self-DM 차단. 새 OTP가 필요하면 재발송 대기 후 승인된 본인 검증만 수행. PAT 혼용/고정코드/인증 우회 금지 |
| DB/Redis 장애 | Compose ps, API/health의 UP 여부, 디스크/자원 상태를 로컬에서 확인 | 신규 참여 안내를 일시 중지하고 복구 담당자에게 전달. 데이터 볼륨 삭제/down -v/FLUSH/테이블 DELETE 금지. 원인 없이 모든 컨테이너를 재생성하지 않음. 복구 후 기존 계정/최초 기록이 유지되는지 확인 |
| 접속 폭주·지연 | 오류율·응답 지연·CPU/메모리·DB 커넥션·MM rate limit 구분 | 사용자에게 재시도 간격 안내, 요청 연타 억제. 무제한 retry/로그인 한도 해제/실서버 부하 테스트 금지. 임의 replica 증설로 중복 워커/설정 분기를 만들지 않음 |
| 미션 제출 후 결과 불명 | 내 슬롯/도전 상태를 먼저 GET 조회, 원래 idempotency key/payload의 재시도 상태 확인 | 새 계정/새 키/재도전으로 우회하지 않음. FAST TAP 원본 입력을 새로 조작하거나 DB에서 VALID로 바꾸지 않음. UI 새로고침으로 payload가 사라졌다면 서버 기록을 우선 확인 |
| 글자 누락 | 해당 미션 해금/서버 상태 → 프로필/현재 동의 → 콘텐츠 승인/최초 evidence → 전체 5개 상태 확인 | 승인 전/검토 중을 완료로 안내하지 않음. SHOW ME는 태그 없이 소개·관심사·필수 동의·행사 OPEN과 자동 재확인 응답을 확인. NFC 해금은 다른 네 미션만 확인. 수집판 이미지 색상만으로 지급 판정 금지. 직접 INSERT/수동 중복 지급 대신 비식별 오류 코드로 조사 |
| 검수 대기 누적/승인 409 | pending revision/fence 최신화, provider NONE/장애와 수동 검수 구분, 검수 마감 확인 | 운영자 화면의 기존 승인/거절/재처리와 사유 기록만 사용. 최신 상태 조회 없이 승인 연타 금지. 거절된 수정본과 기존 승인본을 구분. 마감·동의·공개 조건을 우회하지 않음 |
| 시상/순위 이상 | 사용 중인 시상 구현/규칙 버전 확인. 이 기준 커밋에는 확정/지급 기능 없음 | 후보 공개·경품 지급을 잠시 보류. completionOrder를 최종 순위로 공지하지 않음. 담당 두 명이 동일 기준 자료로 재검토. 임의 동점 정책·중복 수상·후보 삭제·DB 순번 변경 금지 |
| NFC 복귀 실패 | 같은 브라우저/프로필인지, private mode/앱 내 브라우저 전환, pending 15분 만료 여부 | 현장 태그 다시 읽기, 같은 브라우저 로그인 확인. 토큰 URL 전체를 문의/로그/메신저에 게시하지 않음. 공유 링크만으로 해금되는 우회 금지 |

문의 기록은 발생 시각(KST), 화면/미션명, 비식별 오류 코드, 재시도 여부만 우선 사용한다. raw 요청·쿠키·토큰·OTP·DB dump·개인 프로필 스크린샷을 외부 공유하지 않는다. 필요한 식별과 기록 열람은 담당자 승인된 경로에서 최소 범위로 수행한다.

## 배포 전 최종 체크리스트

- [ ] 이 QA/기존 UI/운영 패치의 정확한 조합으로 JDK21 test/bootJar, 실제 MySQL/Redis Testcontainers integrationTest 완료
- [ ] 360/390/430px·PC의 7개 브라우저 계약 테스트와 iOS Safari/Android Chrome 실제 확인
- [ ] NFC→로그인→프로필→읽었던 미션 복귀, 새로고침/뒤로가기/재스캔/15분 만료 확인
- [ ] 모달 Escape/포커스 복귀/긴 정책 스크롤, 화면 키보드·하단 내비·안전 영역·터치 조작 확인
- [ ] FAST TAP 취소 응답 재시도와 다른 탭 도전 복구, 중단/실패/동일 payload 재전송 확인 (실제 참가자의 1회 기회 소모 금지)
- [ ] 행사 일정/UTC 변환·현재 정책 두 종류/가입 전 안내·수락의 운영자 승인과 서버 계약 완료
- [ ] 승인된 전용 MM 발신 계정/권한/운영 담당/종료 후 접근 회수 확인. 실제 발송 검증은 별도 승인 범위에서 수행
- [ ] SYNC 문항·유형·현재 버전 검증. 선택 운 점수 활성 여부/범위와 경품 사용 정책 별도 확인
- [ ] 검수 제공자/수동 검수 담당·검수 마감·ADMIN 계정 확인. 미완료/검수 중을 보상 완료로 안내하지 않음
- [ ] 실제 시상 구현과 규칙/동점/중복/철회/반려/확정·지급 idempotency 검증. 미구현이면 ‘시상 기능 준비 완료’ 판정 금지
- [ ] 보관기간·공개 범위·철회·문의·운영 감사 절차 승인. 미승인 문구를 임의 배포하지 않음
- [ ] 서버 밖 백업/복구 리허설·이전 이미지·설정 변경 이력·인수인계 확보
- [ ] 외부 공개 포트/HTTPS/secure cookie·same-site·CSRF/권한 유지, .env/비밀키 포함 여부 비공개 점검
- [ ] 두 운영자의 장애 연락·참여 중지 공지·경품 보류/재확인 절차 합의

이 체크리스트는 자동 배포 승인이나 행사 규칙 확정이 아니다. 이번 작업에는 배포를 포함하지 않는다.
